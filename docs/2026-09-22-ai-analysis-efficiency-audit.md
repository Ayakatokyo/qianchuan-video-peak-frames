## 执行方式与保留边界

默认通过原有统一 CLI 执行：

```bash
python scripts/run_standard_analysis.py analysis-task \
  --output-dir "$PWD/千川数据资源/<run-id>" --section facts \
  --export-dir "$PWD/千川数据资源/<run-id>/diagnostic-analysis/task-pages-facts"
```

一次返回索引路径、输入哈希、任务数和页数；索引逐页登记路径、字节数与 SHA-256。每页包含完整元数据，最多 8,000 字节。导出拒绝覆盖旧目录或写出本次分析目录，先暂存再整体发布。模型仍须完整读取每个任务的全部分页；`contentReviewed=false`，导出不会冒充已读或完成分析。

首次写一种结构前读取 contract，按字段使用 references。逐素材按 frame-review 返回的真实 taskId 和模板处理，观察与本素材商业解释一起写入正式片段；分类汇总先检查后组装。多个已完成片段可在同一 `check-analysis-part` 调用中显式重复 `--part`，失败时先修对应片段。

仍保留全量成功帧查看、同图 SHA 复用边界、全部素材分析、五包与图片哈希、组装来源校验、最终结构和内容复核。脚本不生成商业解释、不自动替换引用、不自动分类，也不以精简正文为理由删减证据门槛。`scripts/` 仍为 36 个 Python 文件，无新增运行脚本；新增文件仅为回归测试和本审计记录。
